Welcome to GemmaFlow

GemmaFlow is a macOS menu bar dictation app for fast, local voice-to-text. This page is the public update channel used by in-app updates, and it also doubles as a quick getting-started guide when Sparkle sends you here from an update prompt.

Getting Started

  1. Install GemmaFlow into /Applications.
  2. Launch it from Applications, not directly from the DMG.
  3. Grant Microphone and Accessibility permissions when prompted.
  4. Open Settings to choose your ASR and formatter models.
  5. Use the global shortcut and start dictating into any focused text field.

How Updates Work

After the first DMG install, GemmaFlow updates itself in place through Sparkle. When an update is available, use the menu bar app to install the new version and restart without reinstalling from the DMG.

If self-updates are disabled, make sure the app is installed in /Applications or ~/Applications.

Models and Hugging Face

GemmaFlow supports local ASR and formatter models, including custom Hugging Face repositories. For private repos, configure your token in Settings > Models > Hugging Face Access, then add a repo id like owner/repo.
